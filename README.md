# 🌌 TG-Space-Bot

نظام بوت تيليجرام متكامل وجاهز للإنتاج لإدارة الملفات والتخزين السحابي غير المحدود. 
يعمل البوت كواجهة تحكم ذكية وسلسة (Frontend UI)، بينما تُستخدم **مجموعات تيليجرام المخصصة كخلفية تخزين فيزيائية فعلية (Backend Storage)** مع قاعدة بيانات **Supabase (PostgreSQL)** لفهرسة البيانات الوصفية والبحث الفوري وإدارة العمليات (CRUD).

```
| - مجموعة الصوتيات (Audio)     |              | - Storage Stats View          |
| - مجموعة الأرشيف (Archives)  |              +-------------------------------+
+-------------------------------+
```

## 🚀 المميزات الرئيسية

1. **توجيه التخزين التلقائي (Smart Routing):**
   - تحليل نوع الملف تلقائياً عبر فحص الامتدادات و `MIME Types`.
   - توجيه المستندات (`PDF, Word, Excel, TXT`) إلى مجموعة المستندات.
   - توجيه الصور ومقاطع الفيديو والريلز إلى مجموعة الوسائط.
   - توجيه الصوتيات والمقاطع الصوتية إلى مجموعة الصوتيات.
   - توجيه الملفات المضغوطة (`ZIP, RAR, 7Z, TAR`) إلى مجموعة الأرشيف.

2. **قاعدة بيانات وفهرسة ذكية (Supabase / PostgreSQL):**
   - تخزين معرفات الملفات `file_id`، اسم الملف، الحجم، الفئة، ومعرف الرسالة داخل المجموعة.
   - استخدام فهارس سريعة و `Trigram Index` للبحث الفوري عن أي جزء من اسم الملف.

3. **واجهة مستخدم تفاعلية (Interactive UI):**
   - لوحات مفاتيح مضمنة (Inline Keyboards) تتضمن تصفحاً كاملاً مع نظام ترقيم الصفحات (Pagination).
   - إمكانية استرجاع وتحميل الملفات فوراً داخل المحادثة الخاصة.
   - ميزة الحذف النهائي مع تأكيد مسبق (تحديث قاعدة البيانات وحذف الرسالة من المجموعة الفيزيائية).
   - شاشة إحصائيات دقيقة لمساحة التخزين وعدد الملفات لكل فئة.

4. **الأداء والاستقرار:**
   - مبني بالكامل بنمط غير متزامن `Asyncio` وإطار عمل `Aiogram 3`.
   - Middleware ذكي لمعالجة حدود معدل الطلبات (Telegram Rate Limits & Flood Waits).

## 🛠 خطوات التثبيت والتشغيل

### 1. إعداد مجموعات تيليجرام (مجموعات التخزين)
1. قم بإنشاء 4 مجموعات (أو قنوات) خاصة في تيليجرام:
   - مجموعة المستندات (`Documents`)
   - مجموعة الوسائط (`Media`)
   - مجموعة الصوتيات (`Audio`)
   - مجموعة الملفات المضغوطة (`Archives`)
2. أضف البوت إلى كل مجموعة وامنحه صلاحية **مشرف (Administrator)** لإرسال وحذف الرسائل.
3. استخرج معرف المجموعة (`Chat ID`، يبدأ عادة بـ `-100`).

### 2. إعداد قاعدة بيانات Supabase
1. افتح مشروعك في [Supabase](https://supabase.com).
2. توجه إلى **SQL Editor**.
3. الصق محتويات ملف `schema.sql` واضغط **Run** لإنشاء الجداول والفهارس.

### 3. إعداد المتغيرات البيئية
قم بنسخ ملف `.env.example` إلى `.env` :
```bash
cp .env.example .env
```
وقم بتعبئة القيم المطلوبة:
```env
BOT_TOKEN=توكن_البوت_من_BotFather
STORAGE_DOCUMENTS_CHAT_ID=-1001234567890
STORAGE_MEDIA_CHAT_ID=-1001234567891
STORAGE_AUDIO_CHAT_ID=-1001234567892
STORAGE_ARCHIVES_CHAT_ID=-1001234567893
STORAGE_DEFAULT_CHAT_ID=-1001234567890
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=مفتاح_service_role
```

### 4. تثبيت الحزم وتشغيل البوت
```bash
pip install -r requirements.txt
python main.py
```
